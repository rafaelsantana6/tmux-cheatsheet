1. Conceitos básicos

Pense em sessão, janela e pane como camadas do seu ambiente de trabalho.

Sessão

Um workspace inteiro do tmux. Pode continuar vivo mesmo depois que você fecha o terminal.

Janela

Como uma aba dentro da sessão. Boa para separar editor, git, logs e servidor.

Pane

Uma divisão da tela dentro de uma janela. Ideal para rodar comandos lado a lado.

Sessão: trabalho Janela 1: editor Pane 1: nvim Pane 2: servidor Janela 2: git Janela 3: logs

2. Abrir, sair e voltar

O superpoder do tmux é deixar tudo rodando.

criar sessão 
tmux new -s trabalho
listar e voltar 
tmux ls
tmux attach -t trabalho
Prefixd
Desanexa da sessão atual sem matar seus processos.
tmux attach
Volta para a sessão existente, quando houver apenas uma.
tmux kill-session -t trabalho
Mata uma sessão específica pelo nome.

3. Seu Prefix

O prefix é a tecla que avisa ao tmux: “o próximo comando é para você”.

Na sua configuração, o prefix principal é:

CtrlEspaço

O prefix tradicional também continua disponível:

Ctrlb

Quando este guia disser Prefix + c, faça: aperte Ctrl+Espaço, solte, depois aperte c.

4. Janelas

Janelas funcionam como abas. A sua config começa em 1, não em 0.

Prefixc
Cria nova janela no mesmo diretório do pane atual.
Prefixr
Renomeia a janela atual.
Prefixk
Fecha a janela atual.
Alt1..9
Vai direto para a janela pelo número.
Alt←/→
Vai para a janela anterior ou próxima.
AltShift←/→
Move a janela atual para esquerda ou direita.

5. Panes

Divisões rápidas para editor, servidor, testes e logs no mesmo lugar.

Prefixh
Divide em cima/baixo. Na config: split-window -v.
Prefixv
Divide lado a lado. Na config: split-window -h.
Prefixx
Fecha o pane atual.
CtrlAltSetas
Navega entre panes sem usar prefix.
CtrlAltShiftSetas
Redimensiona panes de 5 em 5 células.

Atenção: Prefix+x, Prefix+k e Prefix+K fecham coisas. Use com intenção.

6. Sessões

Use sessões para separar projetos, clientes ou contextos de trabalho.

PrefixR
Renomeia a sessão atual.
PrefixC
Cria uma nova sessão no diretório atual.
PrefixK
Mata a sessão atual.
PrefixP/N
Vai para a sessão anterior ou próxima.
Alt↑/↓
Troca de sessão sem prefix.

7. Cópia, scroll e busca

Você usa modo vi para copiar e navegar no histórico.

Prefix[
Entra no modo cópia.
hjkl
Navega como no Vim dentro do modo cópia.
/
Busca para frente.
?
Busca para trás.
n/N
Próxima ocorrência ou ocorrência anterior.
v
Começa uma seleção.
y
Copia a seleção e sai do modo cópia.
q
Sai do modo cópia.

8. Mouse ligado

Sua config habilita mouse para reduzir atrito no uso diário.

Você tem set -g mouse on. Isso permite clicar em panes, clicar nas janelas da barra, rolar histórico com o scroll e redimensionar panes com o mouse.

9. Recarregar config

Depois de editar o arquivo, recarregue sem reiniciar o tmux.

Prefixq
Recarrega ~/.config/tmux/tmux.conf e mostra “Configuration reloaded”.
alternativa pelo terminal 
tmux source-file ~/.config/tmux/tmux.conf

10. Fluxo recomendado

Uma rotina simples para ganhar memória muscular.

comece uma sessão 
tmux new -s dev
Prefixc
Crie uma janela nova.
Prefixr
Renomeie para algo como editor, git ou logs.
Prefixv
Divida lado a lado.
CtrlAlt←/→
Alterne entre panes.
Alt1/2
Alterne entre janelas.
Prefixd
Saia sem matar nada. Volte depois com tmux attach -t dev.
